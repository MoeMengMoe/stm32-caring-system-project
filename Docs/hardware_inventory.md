## 3. TFT 显示屏

| 项目 | 当前可确认信息 |
| --- | --- |
| 尺寸 | 2.0 英寸 |
| 分辨率 | 240 x 320 |
| PCB 丝印 | `XYTFT-2.0"-SLCM VER1.0` |
| 接口形态 | 8 针只写 4 线 SPI |
| 控制器型号 | 待核对；当前代码默认按 `ST7789` 初始化 |
| 逻辑电压与供电范围 | 当前只允许使用 `3.3V` |
| 状态 | 已分配 STM32 引脚并加入本地状态页代码，待上板验证 |

图片与实物确认的接口丝印为 `BL`、`CS`、`DC`、`RST`、`SDA`、`SCL`、`VCC` 和 `GND`，没有 `SDO`。其中 `SDA/SCL` 是 SPI 数据输入与 SPI 时钟，不是 I2C。仅凭模块外观不能严格确认它使用 ILI9341、ST7789 或其他控制器，也不能确认 `VCC` 是否允许 5V。

在获得商品链接、数据手册或通过上板画面确认控制器型号前：

- 只使用 `3.3V` 供电与 `3.3V` 逻辑。
- 不将控制器型号写成已确认事实。
- 如果背光亮但画面始终为空白，优先检查控制器型号与初始化序列，不盲目更换接线。
