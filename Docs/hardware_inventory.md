## 3. TFT 显示屏

| 项目 | 当前可确认信息 |
| --- | --- |
| 尺寸 | 2.0 英寸 |
| 分辨率 | 240 x 320 |
| PCB 丝印 | `XYTFT-2.0"-SLCM VER1.0` |
| 接口形态 | 从 PCB 丝印看是 SPI 类接口 |
| 控制器型号 | 待核对 |
| 逻辑电压与供电范围 | 待核对 |
| 状态 | 计划使用，尚未分配 STM32 引脚，禁止接线 |

图片中可见的接口丝印为 `SDO`、`BL`、`CS`、`DC`、`RST`、`SDA`、`SCL`、`VCC` 和 `GND`。仅凭模块外观不能严格确认它使用 ILI9341、ST7789 或其他控制器，也不能确认 `VCC` 是否允许 5V。

在获得商品链接、数据手册或通过可靠方法确认控制器型号前：

- 不分配 SPI、CS、DC、RST 或背光引脚。
- 不连接 `VCC`。
- 不添加显示驱动。
