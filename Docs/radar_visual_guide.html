32 个距离门能量示意

每个柱子近似表示一个 10cm 距离门。真实项目日志里的 g00...g31 是相对能量， 不是绝对距离，也不是“风险等级”。峰值门通常接近人体目标，但金属、墙面、桌子也会产生反射。

1. 哪面朝人

正面是带 24GHz 天线图形的一面，通常能看到金色/铜色的天线区域。测试时让这面朝向房间或人。 排针、线束、面包板不要挡在正前方。

雷达发出的不是一根“光线”，更像一个扇形波束。资料里常见水平角约 ±60°，所以侧面也能被看到， 但越偏离中心线，距离和能量越不稳定。

2. 它到底测什么

Rd-03 V2 使用 24GHz FMCW 毫米波。简单理解：它连续发出扫频波，接收人体/墙面/物体反射回来的波， 通过回波差异估算距离，并通过能量变化判断运动、微动和静止存在。

它不像摄像头那样知道“这是手、腿、躺着的人”。我们能拿到的是距离、存在状态、各距离门能量， 所以要用状态机和多传感器融合来判断“疑似摔倒/异常静止”。

现场测试动作清单

测试目标不是“证明它永远准确”，而是记录你的房间里：人站在不同位置时，距离、zone、峰值门和运动评分如何变化。 后续状态机的阈值要从这些真实数据里定。
  1. 正面静站：站在雷达正前方约 50cm、100cm、200cm，各保持 5 秒。观察 TFT 的 xxcm Zx 和 COM6 的 [RADAR_F]。
  2. 远近移动：从 250cm 慢慢走向 50cm，再退回去。正常现象是 distance_cm 总体变小再变大，zone 从 Z3/Z2 到 Z1。
  3. 左右横移：保持约 120cm 距离，从中心线左侧走到右侧。越靠边，能量可能下降或距离跳动，这是波束角度影响。
  4. 坐下/静止：在 Z2 或 Z3 坐下保持 20 秒。正常现象是 presence 仍为 1，motion_score 下降，still_s 开始增长。
  5. 离开房间：走出探测区并等待超过雷达无人延时。正常现象是 presence 变 0，屏幕显示 CLEAR。
  6. 安全模拟跌倒：不要真摔。可以从站立变成坐/躺在垫子上，观察“距离突变 + motion_score 先高后低 + still_s 增长”。这才是后续 POSSIBLE_FALL 的输入模式。
注意：单个 Rd-03 V2 不能可靠地直接识别“摔倒姿态”。我们的产品应描述为“基于雷达、PIR、环境和气体的疑似异常事件判断”，再通过联网告警和人工确认闭环。
