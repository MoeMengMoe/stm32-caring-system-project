# V0.5 演示底板与支架设计

更新时间：2026-07-06

## 1. 当前阶段定位

当前不是最终外壳阶段，而是“结构化原型”阶段。

目标：

```text
固定模块位置
固定传感器朝向
固定供电和线束
让每次采集数据的几何条件一致
让答辩时看起来像一个可演示的护理节点产品
```

不建议现在直接打印完整封闭外壳。因为雷达、PIR、MQ、BME280、屏幕、按钮和继电器的最佳位置还没有经过数据验证。现在应该先做底板和支架，等数据采集和场景验证稳定后，再做最终 3D 打印外壳。

## 2. 总体形态

建议做一个桌面式/壁挂式可切换的演示托盘：

```text
正面朝观众/测试区域

┌────────────────────────────────────────────┐
│  传感器前窗区                               │
│  [PIR] [Rd-03 radar]   [BME通风] [MQ通风]   │
│                                            │
│  主控与交互区                               │
│  [NUCLEO]       [TFT倾斜屏] [SOS] [ACK]     │
│                 [蜂鸣器出声孔]              │
│                                            │
│  供电与执行区                               │
│  [5V电源] [ESP8266]       [继电器] [LED负载]│
└────────────────────────────────────────────┘
```

推荐底板尺寸：

```text
第一版：400 mm x 260 mm
可缩小：360 mm x 240 mm
材料：3 mm 亚克力板 / 木板 / 洞洞板 / 厚 PVC 板
```

如果桌面空间够，优先用 `400 x 260 mm`。不要为了小而把线压得太紧，比赛演示机第一版“稳”和“清楚”比“迷你”更重要。

## 3. 分区设计

### 3.1 传感器前窗区

放在底板前侧，统一朝向测试区域。

#### Rd-03 V2 雷达

作用：主要人体存在、距离、距离门能量、运动/静止特征。

结构要求：

- 正面朝向测试区域。
- 不要被金属遮挡。
- 可以隔着薄塑料，但第一版建议直接露出或只加非金属保护框。
- 固定后不要再随意转角度，否则 AI_SAMPLE 数据不可比较。
- 建议用一个垂直小支架固定，离底板高度约 `60-100 mm`。

已知约束：

- 用户提供图片显示 Rd-03 小板约 `20 mm x 20 mm`，排针间距 `2.54 mm`。
- 接线必须按模块丝印 `3V3 / GND / OT1 / RX / OT2`。
- 详见 `Docs/rd03_v2.md` 和 `Docs/pinmap.md`。

#### HC-SR501 PIR

作用：人体活动粗检测，辅助雷达。

结构要求：

- 白色半球透镜必须露出。
- 透镜朝向应与雷达大体同方向。
- 不要被屏幕、杜邦线、外壳边缘遮挡。
- 第一版建议和雷达放在同一个“传感器立板”上，PIR 稍高，雷达稍低。

已知约束：

- 用户图片中规格表显示 PCB 约 `32 mm x 24 mm`，透镜直径约 `23 mm`。
- 工作电压 `4.5-20V`，输出高电平约 `3.3V`。
- 当前项目接 `A3 / PB0 / PIR_IN`。

#### MQ 气体模块

作用：气体风险趋势和 ppm 估算。

结构要求：

- 必须通风，不能闷在封闭壳体里。
- 远离 BME280，否则 MQ 加热会影响温湿度。
- 远离 5V 电源模块、继电器、ESP8266，减少热和电噪声影响。
- 不要贴着桌面，建议用 `8-12 mm` 支柱垫高。
- 未来外壳需要侧面或顶部开通风孔。

当前约束：

- 使用外部 5V 供电。
- AO 经 `2k/3.3k` 分压后接 `A2 / PC3 / ADC1_IN4`。
- 当前对外展示 `gas_ppm_est`，mV 只保留调试。

#### BME280

作用：温度、湿度、气压。

结构要求：

- 必须通风。
- 远离 MQ、ESP8266、5V 电源模块、继电器线圈等发热源。
- 不要贴近屏幕背光或主控稳压器。
- 建议放在前侧或侧边的独立通风角落。

当前约束：

- I2C1，`D15 / PB8 / SCL` 和 `D14 / PB9 / SDA`。
- 3.3V 供电。

### 3.2 主控与交互区

#### NUCLEO-U5A5ZJ-Q

作用：主控和线束中心。

结构要求：

- 放在底板中部偏后，左右排母都能插线。
- USB-C/ST-LINK 口必须朝外或至少能插线。
- 使用螺丝柱固定，避免插拔杜邦线时整块板移动。
- 不要让传感器支架压住 CN7/CN10/CN11/CN12 排母。

尺寸处理：

- 官方板卡机械尺寸和安装孔位置需以 ST 手册/实物测量为准。
- 当前设计阶段先使用“可调孔位”方案：底板打长圆孔或用扎带孔固定。
- 最终 3D 打印前必须测量板长、板宽、安装孔间距、孔径和 USB 口外伸位置。

#### TFT 屏幕

作用：本地状态展示。

结构要求：

- 放在主控前方或右前方。
- 建议倾斜 `20-30 deg`，方便观众看。
- 8 针排针一侧要留走线空间。
- 不要让屏幕排线和杜邦线挡住雷达/PIR 正前方。

当前约束：

- 2.0 英寸，240 x 320，8 针 SPI，只用 `BL/CS/DC/RST/SDA/SCL/VCC/GND`。
- 当前只允许 3.3V 供电。
- 屏幕实物 PCB 尺寸、孔距需要实测。

#### SOS / ACK 按钮

作用：本地护理闭环。

结构要求：

- 必须放在正面易按位置。
- SOS 和 ACK 必须有明显间隔，避免误触。
- SOS 建议红色或贴红色标签，ACK 建议绿色/蓝色或贴标签。
- 自锁按钮要保证按下/弹起状态肉眼可见。

当前接线：

```text
SOS -> D0 / PG8 / SOS_BUTTON，闭合接地，低电平有效
ACK -> D1 / PG7 / ACK_BUTTON，闭合接地，低电平有效
```

#### 蜂鸣器

作用：本地告警声音。

结构要求：

- 出声孔朝正面或上方。
- 不要被底板贴死。
- 可用小支架固定，旁边贴 `Buzzer` 标签。

当前接线：

```text
VCC -> 3V3
GND -> GND
IO  -> D6 / PE9 / TIM1_CH1
```

### 3.3 供电与执行区

#### 面包板电源模块 / 5V 电源

作用：给 5V 器件供电，例如 MQ、PIR、继电器。

结构要求：

- 放在后侧或左后侧。
- 开关、USB/DC 输入要可触达。
- 必须明确标出 5V、3.3V、GND。
- 所有外设和 NUCLEO 必须共地。

#### ESP8266

作用：STM32 与云端/MQTT/Simon 链路。

结构要求：

- 不要放在金属遮挡下。
- 天线区域外侧留空。
- 远离继电器线圈和长负载线。
- USB 口可触达，便于 Simon 烧录或调试。

#### HW-280 四路继电器

作用：低压 LED 负载演示，后续代表家居联动。

结构要求：

- 放在右后侧或单独执行区。
- 控制端和负载端分开走线。
- 第一版只接低压 LED，禁止接市电负载。
- 端子区旁边贴 `NO/COM/NC` 和 `Relay 1/2/3/4` 标签。
- 如果最终外壳包起来，继电器端子必须有独立开口，避免手伸进线束内部。

当前接线：

```text
IN1 -> D3 / PE13 / RELAY1_IN
IN2 -> D4 / PF14 / RELAY2_IN
IN3 -> D5 / PE11 / RELAY3_IN
IN4 -> A5 / PC0  / RELAY4_IN
DC+ -> 外部 5V
DC- -> 外部 GND
```

触发方式：当前为高电平触发，跳帽在 `H / High Level Trigger`。

#### LED 负载

作用：演示继电器联动。

结构要求：

- 放在右前侧或右边缘，观众能看到。
- 每个 LED 负载贴标签，例如 `Alert Light`、`Offline Light`。
- 低压负载线和 STM32 信号线分开走线。

## 5. 线束策略

颜色建议：

```text
红色：5V / 3V3
黑色：GND
黄色：UART TX/RX
绿色：I2C
蓝色：SPI
橙色：GPIO 输入/输出
白色：ADC
```

走线原则：

- 电源线沿底板边缘走。
- 信号线尽量短，不跨过雷达/PIR 正面。
- 继电器负载线走右侧边缘，不穿过主控和传感器区。
- MQ AO 分压节点尽量靠近 NUCLEO ADC 输入，减少长线拾噪。
- 所有 GND 最终共地，但布局上用“地线母线”整理，避免一团黑线。
- 用扎带座、热熔胶点、线夹或 3D 打印线扣固定线束。

## 6. 第一批建议打印的小件

现在不打印完整外壳，先打印这些小件更划算：

1. Rd-03 + PIR 垂直传感器立板  
   功能：固定朝向和高度。

2. TFT 倾斜支架  
   功能：让屏幕有产品感，便于观看。

3. SOS / ACK 按钮固定板  
   功能：正面交互区更像产品。

4. 线束梳 / 线扣  
   功能：把杜邦线整理成束。

5. NUCLEO 可调固定脚  
   功能：不用立刻知道精确孔距，也能防止主控滑动。

6. 继电器端子保护框  
   功能：低压演示也要表现强弱电隔离意识。

## 9. 后续外壳设计原则

最终 3D 打印外壳必须等以下条件满足：

- 雷达/PIR 朝向和高度已经通过数据采集验证。
- MQ/BME280 放置位置不会互相热干扰。
- TFT 刷新和可读性可接受。
- SOS/ACK 按钮位置符合演示习惯。
- 继电器/LED 负载联动稳定。
- ESP8266 通信稳定，天线不被遮挡。

外壳形态建议：

```text
上半区：传感器窗口 + TFT + 按钮
下半区：主控 + 电源 + 继电器
侧边：通风孔、电源口、调试口
背面：壁挂孔或支架脚
```

不要把 MQ 和 BME280 关在一个没有通风的漂亮盒子里。对这个项目来说，“传感器数据可信”比“外壳完全封闭”更重要。
